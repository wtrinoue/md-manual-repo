# StatusVector
## 概要
　ゲームにはいろいろなパラメータがあり、規定値以外にも加算バフや乗算バフなどいろいろな数値変更が伴う。そこで、攻撃力や防御力などのパラメータを計算する際には以下のような式が成立すると考えた。  

```csharp
float result = (base + add) * (1f + multiply)

// baseは基本の値
// addは加算についての値
// multiplyは乗算についての値
```  

　このような計算が各パラメータで成立するので、これらの値を保持する行列をもたせて、各要素について計算するといいと考え、**StatusVector**という行列を作成した。

| StatusVector | base | add | multiply |
| :--- | ---: | ---: | ---: |
| 攻撃力 (ATK) | 100 | 20 | 0.5 |
| 防御力 (DEF) | 80 | 0 | 0.25 |
| 速度 (SPD) | 10 | 5 | 0 |
| 体力 (MaxHP) | 500 | 100 | 0.1 |

　行について計算することですぐに加算や乗算された数値を取り出すことができる。また、時間変化するバフとしてのStatusVectorをもう一つ持たせれば、行列として足し合わせるだけで時間変化するステータスも表現することができる。  

```csharp
StatusVector originVector;
StatusVector buffVector;

StatusVector rv = originVector + buffVector;// result vector

float atk = ( rv["ATK"]["base"] + rv["ATK"]["add"] ) 
                            * ( 1f + rv["ATK"]["multiply"] );

/*
atkは実際以下のような計算になる。
はじめにベクトルで合わせると計算が楽になる。

atk = (originBase + originAdd + buffBase(t) + buffAdd(t))
            * (1f + originMultiply + buffMultiply(t));

基本的には buffBase(t) = 0 が恒等的に成立するようにする。
ｔは時間を表す。
*/
```

　このように数値計算を行うことで、加算、乗算、時間経過のバフ、永続バフなどのあらゆるステータス変更を実装することができる。  

　このStatusVectorを操作するためのものが**StatusToken**と**Modifier**であり、他のStatusVectorとのやり取りに欠かせない。

## 拡張性
- これは内部データなので、移動速度にSPDを適用したり、相手への攻撃力にATKを適用したりすることで、オブジェクトの移動や他のエンティティーとのやり取りに反映させることができる。StatusVectorはあくまでデータの塊であり、解釈は後で与えられる。
- MVC構造でいうと、Mのモデルの部分にあたるのが**StatusVector**で、モデル間の連携さえ整えればオブジェクトの動きなどのV(View)の部分は自由に作っても問題ない。これが奇抜なアイデアの実装を可能にする。
- 行列の行を増やすことで新しいパラメータを作ることができ、列を増やして式を変更すれば新しいルールを定義することができる。ゲームの規模に応じて簡単にステータスを拡張することができる。  
- ｔは時間を表していたが、ターンを表すようにすると、ターン制RPGのためのステータスに作り変えることができる。毎フレーム変化するのではなく、毎ターン変化するやり方でも考えは変わらない。
