# 公開の仕組み

このマニュアルは **GitHub Pages** で公開できます。
一度設定してしまえば、あとは **`pages/` を編集して push するだけ** で公開中のマニュアルも更新されます。

## 流れ

```text
pages/ を編集
   ↓  git push（main ブランチ）
GitHub Actions が自動で動く
   ↓  npm run build（公開用ファイルを dist/ に作る）
GitHub Pages に公開
   ↓
https://wtrinoue.github.io/md-manual-repo/ が更新される
```

## npm start との違い

| | `npm start`（手元） | GitHub Pages（公開） |
| --- | --- | --- |
| 目次の作り方 | サーバーがその場で `pages/` を調べる | push 時にビルドして `tree.json` を作る |
| 自動再読み込み | あり | なし（ブラウザを更新） |
| `_` で始まるファイル | 表示しない | 公開もしない |

> 手元で `npm start` で見た目を確認してから push する、という使い方がおすすめです。
