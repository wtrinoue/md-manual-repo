# 更新のしかた

設定が終わったら、普段の作業は **編集して push するだけ** です。

## いつもの手順

1. `npm start` で手元のマニュアルを開く
2. `pages/` の Markdown を編集・追加する（保存すると自動で反映されます）
3. 見た目を確認したら commit して push する

```bash
git add pages
git commit -m "〇〇のページを追加"
git push
```

4. 数分待って公開ページを更新する

## ページ・章を増やすとき

- **ページを増やす** → フォルダーに `.md` を追加する
- **章を増やす** → `pages/` にフォルダーを追加して、中に `.md` を入れる
- **順番を変える** → 先頭の番号（`01_`, `02_` …）を付け替える

## 公開前に確認したいとき

```bash
npm run build
```

公開されるファイルが `dist/` に出力されます（`dist/` は Git には含まれません）。
