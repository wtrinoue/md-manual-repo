# 最初の設定（一度だけ）

GitHub Pages を **GitHub Actions** から公開するように設定します。

## 1. Pages の設定を開く

1. GitHub でリポジトリ（`wtrinoue/md-manual-repo`）を開く
2. 上のタブの **Settings** を開く
3. 左のメニューから **Pages** を開く

## 2. 公開方法を選ぶ

**Build and deployment** の **Source** を **GitHub Actions** にします。

> 「Deploy from a branch」のままだと、ビルドされずに README が表示されるだけになります。

## 3. push する

設定ができたら `main` ブランチに push します。

```bash
git add .
git commit -m "マニュアルを追加"
git push
```

すでに push 済みの場合は、**Actions** タブ → **Deploy to GitHub Pages** → **Run workflow** で手動実行できます。

## 4. 公開されたか確認する

**Actions** タブで緑のチェックがつけば完了です。
数十秒〜数分で次の URL に反映されます。

<https://wtrinoue.github.io/md-manual-repo/>
