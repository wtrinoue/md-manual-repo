# 困ったとき

### Actions が赤い × で失敗する

- **Settings → Pages → Source** が **GitHub Actions** になっているか確認してください
- 失敗した実行をクリックすると、どの手順で止まったか確認できます

### 公開ページが 404 になる

- 初回は反映まで数分かかることがあります
- URL が `https://wtrinoue.github.io/md-manual-repo/` になっているか確認してください（最後の `/` まで）

### 編集したのに公開ページが変わらない

- **Actions** タブで最新の実行が終わっているか確認してください
- ブラウザのキャッシュが残っていることがあります。`Ctrl + F5` で再読み込みしてください

### 手元では見えるのに公開ページで画像が出ない

GitHub Pages は **ファイル名の大文字・小文字を区別** します（Windows は区別しません）。

```markdown
![図](images/Sample.png)   ← ファイル名が sample.png だと公開版では表示されない
```

Markdown に書いたパスとファイル名を完全に一致させてください。

### 公開したくない下書きがある

ファイル名やフォルダー名を `_` で始めると、目次にも公開ファイルにも含まれません。

```text
_下書き.md
_メモ/
```

### リポジトリを非公開（Private）にしたい

無料プランでは、Private リポジトリで GitHub Pages は使えません。
公開ページは誰でも見られるので、社外秘の情報は書かないようにしてください。
