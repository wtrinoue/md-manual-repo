# md-manual へようこそ

このマニュアルは **`pages/` フォルダーに Markdown を置くだけ** で、本のように読めるようになっています。

> 左の **目次** から章を選ぶと、その章のページが開きます。
> 章の中は **‹ ›** ボタン、またはキーボードの **← →** キーでめくれます。

## このビューアでできること

- フォルダーがそのまま **目次（章）** になります
- フォルダーの中の Markdown が **ページ** になります
- 同じフォルダーのページは左右に並んでいて、ボタンで流れるように移動します
- 別のフォルダーへは目次から切り替えます
- ファイルを保存すると **自動で再読み込み** されます
